Fabricator is a Linux-first web dashboard for creating and managing Minecraft servers. It combines a Python/Flask backend, a Vue dashboard, Modrinth integration, managed Java runtimes, playit.gg tunnels, backups, player management, and a small system CLI.

## What you can do

- Create and run **Fabric**, **Forge**, **NeoForge**, **Quilt**, and **Vanilla** servers.
- Start, stop, restart, inspect logs, and send console commands from the browser.
- Search Modrinth for mods and modpacks, install compatible files, and remove installed JARs.
- Manage players, whitelist, operators, bans, IP bans, and runtime whitelist state.
- Browse and edit server files safely inside each server's install directory.
- Create manual and scheduled backups, download snapshots, and restore archives.
- Expose Minecraft servers through playit.gg tunnels without router port forwarding.
- Keep Fabricator itself updated from GitHub Releases.

## Recommended next steps

1. Check the [requirements](/getting-started/requirements/).
2. Install with the [one-line installer](/getting-started/installation/).
3. Read the [dashboard overview](/guides/dashboard-overview/) before creating your first server.
4. Put Fabricator behind a [reverse proxy](/getting-started/reverse-proxy/) if the host is reachable from a network you do not fully trust.
