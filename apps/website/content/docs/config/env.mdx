---
title: fabricator.env Reference
description: Full reference for the fabricator.env configuration file.
---

`/etc/fabricator/fabricator.env` is the production environment file loaded by `fabricator.service`.

A typical file:

```ini
HOST=0.0.0.0
PORT=5000
FLASK_ENV=production
SERVER_ROOT=/var/lib/fabricator/servers
SERVER_INDEX_FILE=/var/lib/fabricator/servers.json
```

See the canonical [Configuration reference](/reference/configuration/) for every supported variable, defaults, and safety notes.

Restart after changes:

```bash
sudo systemctl restart fabricator
```
