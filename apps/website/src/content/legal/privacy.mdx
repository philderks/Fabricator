## 2. Hosting via Cloudflare Pages

This website is hosted on Cloudflare Pages, a service provided by Cloudflare, Inc., 101 Townsend St, San Francisco, CA 94107, USA. When you access the site, Cloudflare processes technically necessary connection data, including your IP address, request/response metadata, the date and time of access, the requested URL, the referrer, and information about the browser/operating system in use. This processing is required for secure delivery of the website, load balancing, error analysis, and abuse prevention.

The legal basis is Art. 6(1)(f) GDPR (legitimate interest in the secure and stable operation of the website). More information is available in the [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/).

## 3. Privacy-Friendly Analytics with Umami

This website uses a self-hosted Umami analytics instance loaded from umami.fabricator.site. The analytics are used to understand aggregate website usage, improve the website, detect broken pages, and measure which pages are useful to visitors. The legal basis is Art. 6(1)(f) GDPR (legitimate interest in operating and improving this website).

Umami is configured as privacy-friendly analytics. It does not use marketing cookies and does not create user profiles for advertising. Typical analytics data may include the visited page, referrer, browser, operating system, device type, approximate location derived from technical connection data, the time of the visit, and aggregate download-page interaction events such as the selected platform, clicked download link, copied install command, and release version label. IP addresses are processed only as technically necessary to receive the request and produce aggregated usage statistics.

The analytics data is processed on the website operator's self-hosted infrastructure and is not used for cross-site advertising tracking. If your browser sends a "Do Not Track" signal or blocks the analytics script, the website remains usable.

## 4. Cookies and Local Storage

This website does not use marketing cookies. The website itself may store only technically necessary local preferences in your browser if a feature requires it. The currently embedded analytics setup is intended to run without tracking cookies.

## 5. Local Fonts

The fonts used on this website are served locally from the site itself. Simply loading the page does not cause fonts to be requested from Google or other third-party providers.

## 6. Downloads and Technical GitHub References

This website provides a link to the Linux installation script, download links to project releases on GitHub, and links to the Docker image and compose example on GitHub/GHCR. Data is also transmitted to GitHub/GHCR if you actively click an external link or download.

## 8. Storage Duration

Personal data is stored only as long as necessary for the purposes described above or as required by law. The exact retention period for technical logs depends on the configuration of the hosting provider, Cloudflare. Aggregated Umami analytics are retained only as long as needed to understand website usage and maintain the website.
